# Formatting Notes

This project follows the current ACL LaTeX template layout:

- `acl_latex.tex` is the main report source.
- `acl.sty` and `acl_natbib.bst` come from the official ACL style files repository.
- `custom.bib` contains only the references cited by this report.
- The full ACL Anthology bibliography is not bundled, which reduces upload size and BibTeX processing time.

The report uses `figure*` for wide experiment plots and ordinary `figure` for compact plots. Appendix tables are placed after the bibliography, following the standard ACL template structure.
